# Project Documents

This directory is the project's shared source of truth.

## Start here

For implementation review, start with the [build handoff](handoff/README.md), [PRD](handoff/prd.md) and [ADRs](adrs/README.md).

1. [`01-hackathon-brief.md`](01-hackathon-brief.md) — challenge, judging criteria, constraints, and working principles.
2. [`02-sponsor-capabilities.md`](02-sponsor-capabilities.md) — capability-oriented summary of the sponsor stack.
3. [`03-idea-exploration.md`](03-idea-exploration.md) — candidate ideas and early thinking before selection.
4. [`concept/`](concept/README.md) — the current selected concept and its product definition.
5. [`04-idea-scorecard.md`](04-idea-scorecard.md) — consistent comparison against the judging criteria.
6. [`05-decisions-log.md`](05-decisions-log.md) — material choices, assumptions, and rationale.
7. [`06-build-and-delivery.md`](06-build-and-delivery.md) — build plan, acceptance checks, submission, and pitch preparation.
8. [`07-user-research.md`](07-user-research.md) — research findings, evidence, implications, and unresolved questions.
9. [`tickets/`](tickets/README.md) — executable work items and their sequence.
10. [`source-material/`](source-material/README.md) — supplied reports and other non-conversational source evidence.
11. [`transcripts/`](transcripts/README.md) — original source conversations.

## Document status labels

Use these labels near the top of evolving documents:

- `Status: Draft` — incomplete and open to change.
- `Status: Candidate` — coherent enough to compare or test.
- `Status: Decided` — current team decision; supersede through the decision log.
- `Status: Archived` — retained for history but no longer current.
