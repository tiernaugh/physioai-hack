These are provisional scores based on the smallest version buildable today. They should be revisited after the critical integration spike.

## Scoring guidance

### Core Requirements & Functionality

- **1:** concept or disconnected prototype pieces
- **3:** golden path works with visible limitations
- **5:** robust, reliable, end-to-end workflow in the intended environment

### Innovation & Theme Alignment

- **1:** generic chatbot or retrieval workflow in a new wrapper
- **3:** environment adds useful context or action
- **5:** central value depends on a surprising environmental relationship

### Technical Execution & Integration

- **1:** thin model call or mocked integration presented as real
- **3:** coherent orchestration with one meaningful integration
- **5:** deep integration, clear data flow, robust tool use, and thoughtful failure handling

### Usefulness & Agentic Experience

- **1:** unclear user or novelty-only interaction
- **3:** understandable value and usable human control
- **5:** substantial value, native interaction, intelligent context, and excellent oversight

## Required evidence

For each score, record:

- the observable demo evidence;
- what is genuinely implemented;
- what is simulated or seeded;
- the largest reliability risk;
- the argument against the score.
