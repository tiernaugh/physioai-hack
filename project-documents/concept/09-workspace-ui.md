# Movement workspace and voice notes

Status: Implemented prototype refresh — 2026-09-12
Source: Kingsley's UI-refresh request and subsequent request for a goals hero.

The workspace has **two screens**, following the request to integrate Progress and Activity. Voice note creation now opens in a modal from Today, replacing the separate Voice notes page and the generic Add an update form. Keep the calm green/cream design and the working 3D musculature.

1. **Today:** The header’s **Add a voice note** action and floating plus open voice-note creation. A combined hero pairs current movement goals with the interactive 3D body record and an age-group comparison card. The body embeds the imported consultation prototype: Notes / Progress, shoulder/elbow markers, two dated check-ins and replay. Selecting a marker or Open record expands the same workspace for sourced coach notes, client observations and simulated consultation review. Closing returns to the hero and retains edits for the visit; leaving Today or refreshing clears this in-memory record. The consultation fixtures remain separate from the hamstring status and health-score samples. Health score/status and daily exercises follow below. The comparison is explicitly an example (top 28%, 72nd percentile, ages 35–44), with an info disclosure: Alex’s age is unrecorded and no population benchmark is connected. It is independent of the illustrative 78/100 score. On mobile the body appears directly after the goals. Clicking an exercise opens details; completed sets feed the daily summary and activity log.
2. **Your progress:** A single workspace combines an illustrative strength/health graph and every numbered activity/voice note/comment with a calendar and chronological activity feed. Each graph label shows an original title or transcript/comment excerpt. Selecting it opens the original text and provenance, selects its calendar month/day and shows the relevant feed records. Open voice note opens its saved transcript; View full activity focuses the exact parent entry. Same-day labels stack independently, including saved comments at their own date. Calendar/feed filters leave all graph annotations visible. The graph spaces records by elapsed calendar days. The default calendar/feed covers September 2026; month navigation changes the visible activity range, and All dates opens the full record. Appointments, sessions, voice notes and agent insights all map to calendar dates. Upcoming appointments remain inspectable. Author/status filters, search (including saved comments), completion, attributed notes, voice transcripts and full agent deep dives remain available in the feed; deep dives initially collapse to fit beside the calendar. Download my record exports the shared activity and existing movement record. Old Activity links and voice-save navigation land on this integrated activity section.

Strength is an explicitly illustrative 38 → 69 / 100 sample index, not a measured assessment or a score derived from actual notes. Overall progress retains the fictional health score (48 → 78). Every loaded activity, voice note, agent update and saved comment has a graph annotation. The graph’s date range includes all notes and score snapshots; the strength/health lines end at their last recorded snapshot and never extend into newer notes. The three additional authored August entries remain sample data alongside the existing record.

The goals shown are assumed examples for the existing fictional Alex profile: comfortable walks, confidence on stairs and a consistent routine. They are not extracted from the supplied assessment. Health scores, appointments, body snapshots and agent insights remain sample fixtures. Only user-entered updates, notes, completion and exercise sets reflect current interactions.

**Voice notes from Today:** **Add a voice note** in Today’s header opens the creation modal, also available from Today’s floating plus at the bottom right. Record through the browser microphone or upload audio, listen back, then save. The modal closes once the backend accepts the note and opens the integrated activity feed, which shows pending transcription followed by the original words. Saved entries reopen their transcript and expose Retry if processing fails. A transcript-only fallback remains under More options. Captured audio is temporary, and stopping, cancelling or dismissing the modal releases the microphone.

Creating a note does not ask for a title, update type, region, annotation placement or confirmation. Annotation handling belongs entirely to the agent; implementing that work is deferred. The annotation helpers and any existing browser-local edits are retained, but note creation does not invoke them. Transcripts persist in the existing backend.

Only Today and Your progress are visible; Activity is part of Your progress. The existing assessment and voice inbox components and modal code remain behind the disabled `legacyViewsEnabled` flag. Old `#voice-notes` links open the creation modal over Today. Optional voice data is read from the existing backend for the fictional profile and explicit local tests; local activity completion does not imply clinical approval or backend review.

This updates the current Vite prototype's information architecture. It does not implement the separate recorded-consultation P0 or revise its technical acceptance evidence. User and physio are demo roles; shared activity persists in one browser, with no authenticated multi-user service. The detailed setup and demo contract is in [the application README](../../project-app/README.md).
