# Build and Delivery

Status: Draft

## Timebox

Aim for feature completion by 14:30. Preserve the final hour for:

- golden-path testing;
- failure and recovery checks;
- repository cleanup and setup instructions;
- submission copy;
- a two-minute demo recording;
- social copy.

## Build gate

Do not begin broad implementation until the team can state:

- one target user;
- one environment;
- one natural trigger;
- one context advantage;
- one agentic loop;
- one human-control point;
- one memorable demo moment;
- one explicit out-of-scope list.

## Feature-complete checklist

- The intended trigger starts the workflow.
- The agent receives real environmental context.
- At least one meaningful reasoning or tool-use step is visible.
- The agent changes or returns something in the original environment.
- The human can understand, steer, approve, correct, or stop the consequential action.
- The happy path succeeds repeatedly using prepared demo data.
- The most likely failure has a graceful recovery path.
- Mocked or seeded elements are identified accurately.

## Two-minute demo structure

1. **Problem and place:** show where the work already happens.
2. **Trigger:** let the environment wake the agent naturally.
3. **Agentic loop:** show context, reasoning, action, and human control.
4. **Memorable result:** reveal the outcome rather than describing it.
5. **Why here:** state what the agent knows or can do because it inhabits this environment.
6. **Credibility:** name the meaningful integration and reliability or permission choice.

## Delivery assets

- working repository with setup instructions;
- stable demo data or fixture;
- two-minute video;
- concise project description;
- architecture visual if it helps explain the integration;
- clear disclosure of live, seeded, and mocked behaviour;
- social post.
